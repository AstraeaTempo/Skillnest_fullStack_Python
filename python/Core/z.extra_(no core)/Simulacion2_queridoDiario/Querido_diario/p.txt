 Requisitos para aprobar
 Inicio de sesión y Registro con validaciones:

Los errores de validación se deben mostrar en la página.
Cerrar sesión.
 Página Principal:

Muestra únicamente las entradas del usuario en sesión, incluyendo la fecha
El enlace Borrar elimina la entrada de la base de datos.
El enlace Editar redirecciona a la página Editar.
La página principal debe decir «Bienvenido {{ nombre de usuario }}»
 El enlace «Ver» redirecciona a la página individual de cada entrada.
 Crear una nueva entrada:

Esta pantalla solo es accesada si el usuario inició sesión
Validar que los campos no estén vacíos
 Editar una entrada:

Esta pantalla solo es accesada si el usuario inició sesión
Mismas validaciones que la creación
Los campos están pre-populados la información actual de esa asesoría desde la base de datos.
 HTML y CSS deben reflejar la estructura como mínimo al 75% de precisión.
 Requisitos para BONUS
 En la Página Principal, las entradas aparecen de más reciente a más antigua
 El usuario no puede borrar entradas de otros usuarios, aún y que manualmente altere la URL
 En la creación de la entrada, no puede crearse una entrada con fecha en el futuro
 En la edición, implementar las mismas validaciones.
 El usuario en sesión no puede visualizar entradas de otros usuarios, aún y que manualmente altere la URL
 En la Página Principal, agregamos una barra de búsqueda que redirige a la página de Buscar, donde a través de la URL enviará el término de búsqueda
 La página de Buscar mostrará las entradas que incluyen en Notas el término de búsqueda enviado a través de la URL
